The System

A monochrome language for serious infrastructure.

Legion's design system prioritizes legibility, restraint, and signal over decoration. Everything is built around a single neutral spine — pure black through near-white — with sparing amber signal used only where status truly demands it. Motion is quiet. Detail rewards attention.
